| [assets](../assets/)、[packaging](../packaging/ca/README.md) | 资源许可与 CA 打包入口 |

使用产品锁和当前候选对应的私有离线依赖：

```sh
cargo metadata --offline --locked --no-deps --format-version 1
python3 -B scripts/generate-source7.py --check
node scripts/test-contracts.mjs
node node_modules/typescript/bin/tsc -p tsconfig.contracts.json --noEmit
```

`cargo xtask contracts-check` 调用 Node 全合同检查及 Source7 检查，并传回失败退出码。它需要编译工程任务 crate。Source7 的生成命令是 `python3 -B scripts/generate-source7.py`，I33 合同由 `npm run generate:contracts` 生成。Rust 产品构建和测试按 C8 原卡的准入执行。

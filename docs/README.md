## 贯穿所有方向的交付链

```mermaid
flowchart LR
    A[研究目标与核心用户链] --> B[领域内核与正式命令]
    B --> C[Web 编辑器与页面接口]
    C --> D[Agent 操作当前页面]
    D --> E[用户看到真实变化]
    E --> F[个人空间保存与重开]
    F --> G[内容与画面独立验收]
```

功能广度按这条完整链逐步扩展。第一次就选一条有业务价值的用户链贯穿；不要先堆几百个命令，再把页面接口、文件保存和内容验收留到最后。

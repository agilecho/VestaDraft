# 技能覆盖与练习

本手册的学习目标是：人能理解 Craft 一款软件需要哪些工作，AI 能把用户目标转成新项目、领域实现、Web/Agent/文件链和验证交付。覆盖范围通过下列产出与练习检查，掌握程度通过实际结果确认。

通用工程流程可以复用；复杂领域的算法和格式需要按专题研究、选内核和验证。遇到本手册未覆盖的具体能力，沿 [研究验证](专题/14-软件研究与重建验证.md) 补一手材料及最小样本，不虚构已掌握。

## 工程技能与可检查产出

| 技能 | 主教材 | AI 应能独立产出 | 练习通过条件 |
|---|---|---|---|
| 需求与切片 | 方法 01/02 | 精确用户链和功能边界 | 一次切片含编辑、可见、保存与重开 |
| 行为研究 | [研究专题](专题/14-软件研究与重建验证.md) | 观察计划、证据与行为规格 | 新样本能区分假设 |
| 领域建模 | [模型专题](专题/01-领域模型与编辑算法.md) | 对象、单位、不变量和事务 | 失败不部分修改，撤销正确 |
| 命令/API | 方法 03、[契约模板](模板/命令与页面接口契约.md) | 可发现 schema 和结构化错误 | 人与工具调用相同业务逻辑 |
| UI 交互 | [前端专题](专题/02-前端交互与可访问性.md) | 状态、坐标、输入和焦点设计 | 中文/键盘/拖动与状态一致 |
| 渲染与性能 | [渲染专题](专题/03-渲染图形与性能.md) | 资源、修订、导出和测量 | 最新画面、无旧结果覆盖 |
| Web/WASM | [移植专题](专题/05-原生内核到Web与WASM.md) | 依赖图、平台层和页面桥 | 最终托管地址真实运行 |
| 格式兼容 | [格式专题](专题/04-文件格式与兼容工程.md) | codec、兼容表与迁移 | 语义往返与坏输入拒绝 |
| 保存恢复 | 方法 06 | 快照、确认、外改与重开 | 写成才确认，新编辑仍 dirty |
| Agent 使用 | 方法 05 | 工具发现、调用、自纠与检查 | 读到当前页面及用户手改 |
| 模型/长任务 | [任务专题](专题/06-模型接入与长任务系统.md) | 状态机、计量、取消和恢复 | 无重复付费和脱离任务动作 |
| 权限与扩展 | [安全专题](专题/13-安全扩展与协作边界.md) | 信任/能力表和真实守卫 | 直接/嵌套越界均被拒绝 |
| 测试诊断 | [测试专题](专题/07-自动化测试与故障诊断.md) | 独立预期、最小复现和证据 | 故意错误能使验收失败 |
| 构建维护 | [交付专题](专题/08-构建发布与升级维护.md) | 锁定包、命令、迁移与运行指纹 | 干净目标环境可复现 |
| 平台接入 | [接入指南](接入/01-IntegrateCraft接入与复用边界.md) | 复用点与必要差异 | 真工具/页面/服务/空间贯通 |
| 新会话接手 | [文档骨架](模板/新项目文档骨架.md) | 当前状态、入口与下一结果 | 不依赖旧聊天能继续 |

## 学习与执行路径

人先读 README 和七篇方法建立全貌，再按专题进入工程细节，用 [贯穿实战](实战/从空仓库到Agent实时Web软件.md) 检查理解。AI 从 [AI 入口](AI入口.md) 按任务读取，先产方案与真实接口，再在授权范围实施。

本轮交付的是教材、模板、接口示例和评估资料，检查了结构与契约衔接；没有在空仓库实际实现教学软件，也没有证明任意模型读完后都能自动完成任意复杂软件。后续以实战用户链和对应领域样本验证具体 AI 与项目的能力。

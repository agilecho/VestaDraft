# 单款软件 Craft 方案模板

本模板用于研究和设计阶段。复制后填写可核实内容，删去不适用问题；未知项写清如何验证。填写完成不代表已获施工授权，正式卡由现行发卡方按当前项目流程制定。

## 1. 软件与用户结果

| 项目 | 填写内容 |
|---|---|
| 软件名称与方向 | 文档、数据、图形、音视频、CAD、三维、开发工具等 |
| 目标用户与任务 | 谁从什么输入开始，要交付什么 |
| 首条完整用户链 | Web 打开→Agent 编辑→用户看见/手改→保存→导出→重开续作 |
| 本次功能与格式范围 | 精确到可验的操作和兼容程度 |
| 后续功能 | 有依赖顺序的下一条用户链 |
| 明确限制 | 尚不支持什么、失败时向用户怎样说明 |

## 2. 研究基线

列来源、版本/提交、制品摘要、环境、输入样本与日期。每项结论标明源码事实、仓库自述、实际运行或设计建议。引用具体文件或证据目录，秘密不入材料。

| 能力 | 当前事实 | 证据 | 未知项及有边界的验证 |
|---|---|---|---|
| 领域核心 | 填本款实际能力 | 文件/观察 | 明确问题 |
| Web 编辑 | 页面是否完整可编辑 | 文件/运行 | 缺口 |
| 页面 API | 当前引擎能否调用 | schema/结果 | 缺口 |
| CLI/MCP | 工具、参数、范围 | 发现/调用 | 缺口 |
| 文件与资源 | 导入、工程、导出 | 内容/读回 | 缺口 |
| 中文与性能 | UI、字形、输入法、资源 | 真实画面/测量 | 缺口 |

## 3. 方案比较与选择依据

比较实际成立的路径：复用原内核补 Web、在现有 Web 编辑器补薄接口、另建领域内核、仅接正式工具等。写明成本来自哪些缺口、哪条满足实时页面目标。推荐方案与已由用户确认的决策分开登记。

## 4. 内核与命令

描述文档/工程模型、对象身份、领域计算与精度、撤销和事务。列本次新增或复用的命令 ID、完整参数来源、文档选择、返回与错误、副作用、batch、取消和分页。

## 5. Web 与实时页面

描述当前页面状态在哪里、手动操作和 Agent 如何到达同一引擎、页面就绪和渲染完成如何确认。已有页面 API 直接复用；无接口时指出原控制器和最小接缝。说明来源校验、旧回执、切稿和后台节流的处理。

## 6. 文件与保存

区分导入源、当前工程、另存目标、导出副本。说明保存字节、宿主写入、原生确认、dirty、快照后修改、外改、空间满和关闭失败。多文件工程列资源引用、迁移与缺失策略；明确关页重开时读取哪个实际文件。

## 7. IntegrateCraft 接缝

列将复用的具体模块与本款差异：静态包、软件目录、MCP、page/tools、协调器、个人空间、只读、模型、网络、审计、镜像和构建锁。尚无权限或未核实接口不填成已存在能力。

## 8. 验收与证据

| 用户结果或异常 | 输入与独立预期 | 真实入口 | 环境/制品 | 通过条件与证据 |
|---|---|---|---|---|
| Agent 修改当前页面 | 精确内容/参数 | 正式工具与实际页面 | 锁定版本 | 状态与画面都变化 |
| 人机连续操作 | 用户手改后工具继续 | 同一文档 | 同上 | 无分叉、无覆盖 |
| 保存与重开 | 工程及导出 | 生产文件桥 | 同上 | 新页面读回并可续改 |
| 关键异常 | 外改/满额/断线等 | 实际服务 | 对照身份 | 拒绝正确、内容可恢复 |
| 平台边界 | 空间、只读、模型/网络 | 服务端入口 | 对应环境 | 新增能力受既有治理 |

仅新增/直接关联的逻辑补单测；已有测试复用，完整关口按届时卡面执行。替身与实机分别列，未测项保留。

## 9. 构建和交付

锁源码、依赖、补丁、字体/i18n、工具链、构建镜像与目标架构；列产物身份和运行加载核对方式。交付可复现包、使用说明、验证结果与剩余缺口。

## 10. 进入施工前需要明确的事项

列真正影响业务范围、平台政策、资源、额外权限和预算的未定项；普通实现选择由执行者在卡面内处理。前置研究未完成就保持研究状态，不把占位命令交给新会话直接执行。

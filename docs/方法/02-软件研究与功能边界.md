# 软件研究与功能边界

研究应产出能约束实现的材料：用户要完成的工作、领域规则、可用输入、现有接口、格式能力、可运行的技术路径与未知项。截图、反编译和命令清单分别提供不同证据，不能相互替代。

## 1. 固定研究基线

记录目标软件与参考实现的来源、版本或提交、运行系统、制品摘要、输入文件和研究日期。源码事实、仓库自述、本轮实测、设计建议分别标注。共享上游保持只读；需要试验时按届时授权使用独立输入和证据目录。

优先读现有文档和接口，再观察实际行为。面对没有源码的制品，按研究授权和目标确定是否需要静态分析、运行观察或外部引擎；不因装有分析工具就自动扩大研究范围。

Craft Anything 能辅助格式识别、代码分析、功能线索和证据组织，见 [项目分析](../参考/CraftAnything-项目分析.md)。它的 Clean room 默认模式不允许读取原始代码；需要内部分析的任务必须明确其模式和研究范围。

## 2. 先研究完整任务，再拆控件

每条用户链至少观察：

1. 从什么入口开始，输入包含哪些文件与用户选择。
2. 操作改变哪些领域状态，哪些只是视图变化。
3. 画面何时更新，长任务能否取消，失败后保留什么。
4. 保存与导出分别生成什么，再打开保留什么。
5. 哪些数值或规则必须精确，哪些视觉细节可以分阶段接近。

例如 CAD 的约束求解、表格的公式重算和音频的采样时间不能靠界面相似度判定；应先列出可算出的预期，再安排页面表现。

## 3. 按软件方向补研究项

| 软件方向 | 先确定的领域能力 | Web 化重点 | 典型验收结果 |
|---|---|---|---|
| 文档与排版 | 段落、字符、表格、分页、样式与图片 | 字体、输入法、布局稳定、文件桥 | 内容结构、页数与导出重开 |
| 表格与数据 | 单元格类型、公式、依赖、重算、合并区域 | 大表渲染、编辑与重算协同 | 公式及缓存值、范围与格式 |
| 矢量与界面设计 | 场景树、几何、样式、约束、组件 | 命中、缩放、选择、DPR | 节点结构、坐标和 SVG/图片 |
| CAD 与参数建模 | 单位、几何、约束、拓扑与尺寸 | 视口、精度、内核可移植性 | 几何数值、约束和格式读回 |
| 图像与照片 | 色彩、位深、图层、非破坏编辑、原片引用 | 解码、GPU、内存、大文件 | 像素/色彩、原片保护和工程引用 |
| 音频 | 时间基、采样、轨道、效果与混音 | AudioWorklet 等浏览器边界需逐项核实 | 时长、声道、信号变化和导出样本 |
| 视频与动效 | 时间线、帧率、素材、关键帧与合成 | 编解码、GPU、异步就绪与后台节流 | 帧时刻、关键帧、素材与成片 |
| 三维与材质 | 场景、变换、网格、UV、节点与资源 | WebGPU/WebGL、着色器和资产传输 | 拓扑/参数、渲染和资源完整性 |
| 代码与开发工具 | 项目树、编辑、语言能力、运行与调试 | 远端执行隔离、终端和预览来源 | 源文件、编译/运行、诊断与保存 |

这些是研究问题，不是对某款软件已有能力的宣称。目标范围确定后，只选相关方向写实。

## 4. 四类接口逐一核实

| 接口 | 核实内容 | 交付证据 |
|---|---|---|
| 核心命令 | 注册表、schema、文档 ID、batch、错误与副作用 | 实际命令清单与典型调用结果 |
| Web 页面 | 是否能对当前引擎调用、是否异步、何时完成 | 真实页面状态前后对照 |
| 文件 | 打开是入队还是完成、如何取保存字节、谁清 dirty | 导入、保存确认和重开结果 |
| CLI/MCP | 真正支持的参数、读写范围、持久 Session、生命周期 | 工具发现、调用及边界验证 |

同系列软件也不能假定接口一致。WordCraft 的 `command/commands/query` 与其他软件的 `id/steps/filter` 就有差异；别名应保留原 schema。

## 5. 从能力线索到可施工结论

对每个关键能力登记“存在性、实际可用范围、输入限制、未验证项、失败影响”。未知能力要安排有边界的研究，例如只验证“页面能否通过原控制器设置一段中文并导出有效文件”，不在研究中顺手扩为全量实现。

下列情况应先缩小结论：只有桌面实现、只有头信息解析、只有合成样本、只有源码未构建、依赖私有服务、需要目标 OS/设备、格式导入导出不对称。明确缺口是后续实现的输入。

## 6. 功能优先级和兼容范围

按高频完整用户链、领域前提、实现风险和验收可行性排序。为每种格式分别写明能读取、编辑、保存、导出到什么程度；输入允许打开，不代表能够无损回写。

首个切片使用小而有区分度的样本；下一轮增加复杂内容和异常输入。样本应能暴露缺陷，例如同时包含中文、表格与图片的文稿，包含跨区域引用的表格，包含外部素材的时间线。避免只有空白工程或纯色截图的演示样本。

研究输出填入 [方案模板](../模板/单款软件Craft方案模板.md)，并引用具体文件、命令结果或观察记录。参考历史数字时保留日期和证明范围。

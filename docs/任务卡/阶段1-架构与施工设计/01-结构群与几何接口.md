### 4 验收断言与必要验证

| 必验内容 | 设计应证明什么 |
|---|---|
| 相与群 | 非正交两相的基底/R/t生产消费明确；缺父、循环、多个断根有明确失败状态；一般/磁/调制群不由3D供给算子子集冒称全支持 |
| 张量/不确定度 | 单位/基底/来源有闭合映射；`variance=J C Jᵀ`、`σ=√variance`；笛卡尔有界控制与原生fractional/cell缺口分开；缺失协方差不是0 |
| ADP与显示 | PSD、零、负特征值分别处理，B/U换算、椭球概率、半径/字体资产来源明确；不静默夹断负张量 |
| 周期对象/几何 | 选定像保留身份，label不作ID；去重阈值、递归边界、键价表、平面退化有独立预期或明确阻塞，不用最近像替代用户所选像 |
| shape | 延续R7多边形→Mesh投影正反例；空/无界/降维半空间分别给设计判定及独立推导，说明其是否机器验证，不能用面积和相等代替覆盖/朝向 |
| 视图与命令 | GUI/CLI相机顺序、单位/宽度和渲染完成时刻一致；命令由Engine准入/提交，纯job不自行写宿主 |
| 可接手性 | 本卡14组公共字段、相邻消费方、完整来源映射、预期与未证项均可定位；仅“引用存在”不能验收整组 |

验证cwd为ROOT；命令及脚本接口用[共同约定§5](00-共同执行约定.md)。设计正例、错owner/旧epoch/非法张量/非法群/退化几何反例均须在正确层判定；来源、类型、判定或保全失败非零。独立演算和书面走查分别留原始结果，不借用未来生产实现造预期。

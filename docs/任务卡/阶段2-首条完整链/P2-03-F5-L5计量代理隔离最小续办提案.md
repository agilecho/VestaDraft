## 给执行者看的

### 1. 让计量代理成为 Cargo 唯一的出站通道

- 在后继执行目录生成一份固定 SBPL。拒绝网络操作，**仅按规范化绝对路径精确放行出站 Unix 套接字**，移除 `remote ip "localhost:17732"`，规则中没有 IPv4 或 IPv6 出站例外。预检与正式解析使用同一规则文件及 SHA。Unix 路径选用本轮私有目录内的短路径，检查父目录所有权和权限、路径长度及实际解析结果。套接字仅由监督组代理持有监听端，Cargo 与其 Git 子进程只获得显式的标准流，不继承已连通的网络文件描述符。按 Unix 套接字路径限制是本机待验证的 SBPL 候选，现有开源实现有相同类型的匹配方式。[macOS sandbox-runtime 实现](https://github.com/anthropics/sandbox-runtime/blob/main/src/sandbox/macos-sandbox-utils.ts)
- 将原计量代理的本地接入口改为 **SOCKS5 over Unix socket**。只接受域名形式的 `CONNECT`，由代理解析域名。沿用原已审 Git 封存来源、官方 registry 主机及 HTTPS 443 白名单。其他目的地、IP 字面量、`BIND` 和 `UDP ASSOCIATE` 一律拒绝。Cargo 的 `CARGO_HTTP_PROXY` 由 `socks5h://localhost` 与套接字的绝对路径直接拼接。Git 守卫继续核实 fetch 对应的精确 URL 与 rev，并设置同一进程级代理。清除 `NO_PROXY` 等绕行环境，保持 TLS 校验和原私有缓存，禁止直连回退。HTTPS 目的地主机由代理守卫，Git 仓库路径与 rev 由本地守卫核实。[Cargo 代理配置](https://doc.rust-lang.org/cargo/reference/config.html#httpproxy) · [libcurl Unix 套接字代理](https://curl.se/libcurl/c/CURLOPT_PROXY.html) · [Git 代理配置](https://git-scm.com/docs/git-config#Documentation/git-config.txt-httpproxy)
- 代理沿用全卡 **2 GiB** 累计额度。读取上游数据前检查可用字节，按本次实际接收量入账，失败和中断前的数据照计。达到上限停止上游读取并关闭通道。代理、监听端和子进程受同一监督组控制。沿用原并发、资源限制和固定来源。[已审接入方案](/Users/agilecho/code/VestaDraft/docs/任务卡/阶段2-首条完整链/P2-03-公共框架接入整改最终方案.md) · [N1–N3 登记](/Users/agilecho/code/VestaDraft/output/vesta-execution/20261121-p2-03-final-framework-plan-review-recheck/RECHECK.md)

文档依据证明配置语法可作为候选。本机固定 Cargo 与 Git 的实际支持须由运行证据确认。若客户端不支持 Unix 代理或握手失败，保留记录并停报。

### 2. 先在本机验证隔离和计量

获准后预留 F5/L5 一组。先完成实际入口及 Git 守卫的语法与失败阻断检查，再使用正式 SBPL 对以下探针取证。模拟阶段的代理没有真实上游连接。

| 探针 | 通过条件 |
|---|---|
| 指定 Unix 套接字 | 沙箱内连接选定路径，完成本地 SOCKS5 握手并收到预期模拟应答。记录规则 SHA、套接字路径及请求目的地。可让系统 curl 也经同一套接字请求模拟代理，凭明确的握手日志核配置形式 |
| 另一 Unix 套接字 | 用同目录的另一真实监听端做对照。沙箱外可连，沙箱内明确拒绝。以此检查规则精确到单个套接字 |
| 本机非环回 IPv4 同端口 | 保留 F4/L4 的持续监听方式，用 17732 作测试端口。对同一地址与端口先在沙箱外成功 `connect` 并 `recv` 预期字节，再在沙箱内独立记录 `connect`。结束后在外部复查监听正常 |
| IP 实际出站限制 | 非环回同端口及旧环回代理端口的沙箱内 `connect` 均须返回 `EPERM/EACCES`，或有对应进程和目标的可核实系统拒绝记录。可建立本机 IPv6 对照时同样检查，并记录覆盖范围 |
| 白名单、字节和清场 | 模拟拒绝未知主机、协议命令和错误 Git URL/rev，证明计量到限即停止，检查全部监听线程及探针进程已退出 |

分开记录 `connect` 和 `recv`。禁止路径一旦连通就立即判失败，记录 `recv=未执行`。超时、无监听、连接被拒绝或读取失败均不计作沙箱明确拒绝。监听端持续应答，接受事件按源端口和探针记录关联。本机探针不发出真实外网请求。

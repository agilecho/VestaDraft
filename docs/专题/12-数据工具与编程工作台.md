# 数据工具与编程工作台

这类软件主要管理结构化记录、查询或源代码项目。Web 编辑体验与后端执行都重要；任意用户代码的执行权限和可信编辑器本身的权限要分开。

## 数据模型与查询

定义记录身份、schema、类型、缺失/空值、约束、排序和过滤。展示行序号不作持久身份。编辑单元格先校验类型/约束，再提交；失败保留可修正输入。

查询结果有输入版本、参数和分页语义；显示截断要明确。大数据分批处理，排序/聚合语义在完整数据上定义，不能只对当前 UI 页计算后称全局结果。

导入记录编码、分隔符、日期/时区和数值解释；导出保持约定类型。数据库变更用明确事务，读取工具不接受隐藏写入语句。多用户共享编辑若不在当前范围，先明确单用户/单写者契约。

## 源代码编辑器

项目树、文本缓冲、磁盘文件、语言诊断和运行任务分别建状态。未保存缓冲不等于磁盘内容，外改检查和保存确认仍适用。重命名/移动需要处理引用和诊断失效。

语言服务是一个有协议和生命周期的可选服务：记录文档版本、增量变更、诊断与请求取消；旧版本诊断不覆盖新文档。不能把文本框和语法着色登记为完整 IDE。

## 构建、终端与运行

前端发结构化运行请求，后端以受限工作目录和环境执行。进程有所有者、任务、输出上限、超时和停止树；终端连接断开不自动代表进程已结束。

工具链按已授权镜像提供，依赖下载走现有网络规则。用户代码不接平台令牌、管理接口或宿主容器 socket。构建成功还需实际运行与结果检查。

## 预览与调试

生成网页运行在隔离来源，通过被授权任务映射端口/产物。当前项目的任意 `localhost` URL 不能直接交远端用户浏览器。反向代理核身份、任务、协议升级、端口归属和销毁。

调试接口只附着授权进程，断点、暂停和变量读取记录实际状态。不存在目标时明确失败，不能返回空集合冒充成功。

## Agent 接口

提供 schema/项目发现、内容读写、查询、构建、运行、诊断、停止和结果检查。业务软件的编辑通过领域命令；编程工作台允许编辑源代码，但继续受真实文件和执行边界约束。

大文件和结果分页，工具反馈当前版本及写入状态。AI 根据具体诊断修正，不能拿持续重试代替最小复现和环境检查。

## 练习与交付

数据工具：带空值、中文和数值的样本导入，修改、过滤、排序、导出重开，核全量语义。编程工作台：修改小程序、保存、构建、运行并核输出，制造一个语法错误再修复，停止后无所属残留任务。

交付数据/项目状态模型、查询/运行契约、保存边界、预览隔离及上述完整链。code-server 等候选的实际集成另行研究，不能以通用方案登记已接入。

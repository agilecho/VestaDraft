# 文档、表格与演示软件

本方向的难点是内容语义、排版/计算和文件兼容共同成立。界面里的文字、导出后的字节与重开后的领域内容要相互对应。

## 文档编辑器

建模文本块、段落与字符样式、列表、表格、图片、页面设置及引用。区分继承样式和直接格式，避免“工具栏显示加粗”却没有改变持久模型。

编辑操作包括插入、删除、分段、合并、设置范围属性和结构操作。选区要能跨文本节点；Unicode 与输入法处理放在正确层，不能用字节索引直接代表用户字符位置。

布局分行内测量、行断开、块流和分页；浮动、表格跨页等按明确范围逐步支持。先用固定字体和页面样本保证基本排版，再扩兼容。字号、页边距和行高统一单位。

Agent 操作优先用段落/结构身份和明确范围，检查正文、样式和页布局；替换文字前核目标唯一性或明确所有命中。

## 表格软件

单元格保存输入类型、公式表示、样式和必要元数据；计算结果是派生值。公式先词法/语法解析为表达式，引用收集形成依赖图，重算受影响节点并处理循环。

明确相对/绝对引用、范围、错误值、空值和数值规则。插行、复制公式、重命名工作表会改变引用语义，需要专门操作。不要将公式当普通文本做任意字符串替换。

复杂函数先限定支持集合，不支持时返回明确错误；不能悄悄用旧缓存值冒充重算。CSV、工作簿和图表导出分别验类型、公式与可见结果。

## 演示软件

建模演示文稿、幻灯片顺序、母版/主题、对象、媒体和备注；对象坐标与页面比例明确。多页操作带页身份，当前页只属于会话选择。

缩略图、编辑视口和导出使用相同场景；变更母版后正确失效相关页缓存。动画和播放能力如果没实现，保存/导出时明确范围，不能以静态截图代表播放链。

## 中文与资源

正文排版、界面字体和导出字体分别核。图片、超链接、嵌入对象和模板引用有资源身份；导入时决定嵌入还是保留链接并记录失效行为。

WordCraft 的页面协议与保存确认是平台样板，不能把它的分页、batch 参数或文档格式直接搬到表格/演示内核。

## 练习与验收

文档：中文标题、两段正文、2×2 表格和图片，修改表格后分页/导出/重开正确。表格：A1=2、A2=3、A3=SUM(A1:A2)，修改 A1=7 后 A3=10，复制和插行按定义保持引用。演示：三页有不同对象，重排、改色和导出后页序正确。

工具编辑当前页面后由人手改，再由工具检查。语义、计算、画面和导出各有独立预期。范围从一个完整切片扩展，不将整个 Office 兼容一次性写成承诺。

# 模型接入与长任务系统

输入是软件是否需要模型、外部任务或内部 Agent；输出是可计量、可取消、可恢复的任务链。先区分软件业务命令与生成模型服务，已有 dsh Agent 能完成的推理不再默认增加一套内部循环。

## 服务形态

| 形态 | 契约重点 |
|---|---|
| 同步领域命令 | 状态提交、错误和当前页面可见 |
| 长计算/渲染 | 任务 ID、进度、取消和资源清理 |
| 外部异步生成 | 提交幂等、供应商任务 ID、查询、产物和真实费用 |
| 内部 Agent 多轮 | 每次模型与子工具的上下文、权限、预算和审计 |

能力接口不直接暴露某家响应字典；归一化任务状态和结果，再保留供应商诊断字段用于受控排查。不得以自由文本前缀作为成功判定。

## 状态机与恢复

至少区分排队、运行、等待用户、成功、失败、取消中、已取消和结果未知。状态转换有原因和时间；只有实际终止才报告已取消。网络超时不自动等于供应商未接单。

提交前生成幂等请求身份，持久保存已确认的外部任务 ID。重启后查询真实状态，不能重新提交付费任务。产物下载失败与生成失败分开，已生成结果可继续下载。

## 取消与进度

取消沿调用链传播到计算、子进程和可取消的外部任务。不能取消的供应商操作明确报告仍可能产生费用，并停止本地后续动作。轮询有有界退避、截止和进度；不因页面后台节流就丢掉任务所有权。

每个进度事件带任务、阶段和序号。客户端重连从已知状态恢复，重复事件幂等。后台任务结束时更新持久状态，界面订阅只负责显示。

## 统一模型与凭据

在 IntegrateCraft 内继续使用平台网关，真实供应商 Key 留在受管服务。只有 Chat Completions 请求兼容并不足以接通平台任务上下文，见 [Craft Anything 接入评估](../参考/CraftAnything-IntegrateCraft接入评估.md)。

重试、压缩、标题和检查等辅助模型请求同样归任务。价格、计费标签和周期按调用开始时的真实来源，未知用量保持未知；软件自己的估算仅作提示，不替代平台结算。

## 结果进入软件

外部结果先校验格式、尺寸、资源和完整性，保存后通过本款正式命令导入当前工程。生成任务返回时用户可能已换稿，结果不能自动插入另一工程；保留原任务关联并让用户选择后续动作。

长任务的预览、最终产物与工程引用分别登记。素材生成成功不等于已保存进用户工程，命令需返回真实导入与保存状态。

## 练习与验证

使用明确标为替身的任务服务验证：提交后断线、重复提交、重启恢复、取消失败、下载重试和迟到结果。再按授权做真实往返，所有辅助请求可对账。

交付状态图、幂等和恢复契约、费用来源、权限边界及失败样本。开发和文档阶段不自行发付费调用。

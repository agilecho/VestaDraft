# 图形、CAD、三维与材质软件

先区分矢量场景、精确几何、三维拓扑和着色网络。它们可以共享视口和资源机制，领域模型和正确性判定分别设计。

## 二维矢量与界面设计

以稳定 ID 的场景树表达对象、父子关系、几何、样式和布局约束。局部/世界变换显式换算；命中、选框、导出和 Agent 坐标采用同一约定。

路径表示需要明确线段/曲线、闭合、填充规则和描边。布尔运算、文字转路径等复杂操作先评估成熟内核；失败返回原状态。组件实例覆盖与普通复制分别建模，不能靠标题前缀推断。

## CAD 与参数化

核心表示应覆盖单位、几何对象、约束和依赖。求解结果要区分满足、欠约束、过约束与失败，报告具体对象；不能只移动屏幕顶点来伪装尺寸约束。

公差按量级与算法定义，不用一个随处硬编码的小数替代所有精度。参数修改按依赖重新生成，拓扑身份/引用失效有恢复策略。二维工程图与三维实体能力分别登记。

## 三维场景与资产

明确坐标系、单位、旋转约定和层级变换。网格包含顶点、索引、法线及 UV 等属性；导入后检查索引、退化面和资源引用。编辑器辅助物与最终导出场景分开。

视口相机和最终渲染相机的关系写清。操作局部/世界坐标、父节点变换和模型缩放时，Agent 返回真实模型值，避免读渲染矩阵片段猜领域状态。

## 材质与贴图

用类型化节点/边表达程序化网络，校验端口、循环和资源。贴图绘制需要图层、遮罩、UV 与笔刷/颜色空间；预览缓存不当作可编辑工程。

节点改参后先失效相关子图，再重算输出；异步编译或烘焙带文档/修订，旧结果不得覆盖新材质。跨软件交换要定义中间格式、纹理通道和单位，不以桌面联动替代 Web 证明。

## 实现顺序

先完成少量对象的创建、选择、变换、检查和工程保存；再做约束、布尔、拓扑、节点等领域操作；最后扩格式和性能。每步同时保留人和 Agent 入口。

专业内核选择按精度、目标平台、维护与许可声明核实。AI 应能辨认内核不具备的能力，安排小输入研究；不能返回一张形似的图片代替有效几何。

## 练习与验收

矢量：三个对象含父子变换，移动与 SVG 导出坐标一致。CAD：已知长宽的草图加尺寸约束，改参后检查数值和失败回滚。三维：立方体变换、材质和导出重开，核几何和引用。材质：改一个参数，预览及持久图同时变化。

同时验证工具→当前页面、手改→工具读取、保存确认和新页面续作。数值与拓扑检查优先，截图作为表现证据。

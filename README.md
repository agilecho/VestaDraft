## 仓库范围

本仓库保存项目文档和仓库配置。研究原始证据、截图、复审材料及编译缓存所在的 `output/` 按用户选择保留在本机，不纳入 Git。

文档中指向 `output/` 或本机其他目录的链接依赖本机资料，单独克隆本仓库无法访问这些内容。项目当前状态、已接受范围及后续任务以文档内的权威入口为准。
